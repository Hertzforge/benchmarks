# Parity Vectors

`matrix_parity.json`, `laws_parity.json` and `amplitude_parity.json` are copied unchanged from the Hertzforge
repository, `crates/hertzforge-mimo-sine-law-math/tests/data/` at commit 9a4c7b80 of its main branch. The shipped Rust
laws are held to them there; `tests/test_pyloop.py` holds the suite's Python laws (`sine/pyloop/`) to them here
(`sine/pyloop/parity.py`).
