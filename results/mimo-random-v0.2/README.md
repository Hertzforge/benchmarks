# Reported Results: MIMO Random Suite, Version 0.2

One folder per reported result, as `../README.md` describes. Each is listed on
hertzforge.com/benchmarks/results/ beside the baselines once it is merged.

The baselines, the six control laws Hertzforge ships, are not kept here: their 3,793 scorecards, with the
ten held-back structures and the audit's own record, are the results record of the study,
https://doi.org/10.5281/zenodo.24310746, and the paper that reports them is Hertzforge Journal 2026-009.
